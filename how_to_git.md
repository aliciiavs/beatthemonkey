**Use Git Commands**

1. Copy the repository
```bash
git clone https://github.com/aliciiavs/BeatTheMonkey.git
```
2. To add files to Git
```bash
git add .
```
3. To commit the changes + message title
```bash
git commit -m "Initial commit"
```
4. To upload the change into GitHub
```bash
git push -u origin master
```
5. For pulling
```bash
git pull
```
